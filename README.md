# ЛАБИРИНТ (Labyrinth)

Классическая 2D-аркада, написанная на Python с использованием библиотеки **Pygame**. Игроку предстоит провести главного героя через запутанный лабиринт, избегая патрулирующего киборга и столкновений со стенами, чтобы добраться до сокровища.

## Особенности игры
* **Система жизней:** У игрока есть **3 попытки** на прохождение уровня. При столкновении со стеной или врагом игра ставится на паузу (3 секунды), снимается одна жизнь, а позиции персонажей сбрасываются.
* **Патрулирующий противник:** Киборг автоматически перемещается по заданной траектории, преграждая путь к цели.
* **Звуковое сопровождение:** Фоновая музыка джунглей и звуковые эффекты при победе или поражении.
* **Визуальный интерфейс:** Отображение счетчика оставшихся жизней и экранов победы/поражения.

## Управление
Перемещение персонажа осуществляется с помощью стрелок на клавиатуре:
* `↑` — Движение вверх
* `↓` — Движение вниз
* `←` — Движение влево
* `→` — Движение вправо

## Требования и установка

Для запуска игры необходим установленный **Python 3.x** и библиотека **pygame**.

1. Клонируйте репозиторий или скачайте файлы проекта:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-с-проектом>
   ```

2. Установите библиотеку Pygame:
   ```bash
   pip install pygame
   ```

3. Запустите игру (замените `main.py` на актуальное имя вашего скрипта):
   ```bash
   python main.py
   ```

## Структура необходимых файлов (Ассеты)
Для корректной работы программы в одной директории со скриптом должны находиться следующие медиафайлы:

* **Изображения:**
  * `background3.png` — фоновое изображение (масштабируется под `700x500`)
  * `hero.png` — спрайт главного героя
  * `cyborg.png` — спрайт врага и иконка окна игры
  * `treasure.png` — спрайт финальной цели (сокровища)
* **Звуки:**
  * `jungles.ogg` — фоновая музыка
  * `kick.ogg` — звук проигрыша / столкновения
  * `money.ogg` — звук победы / сбора сокровища

## Архитектура кода
* `GameSprite` — базовый класс для всех игровых объектов, отвечающий за отрисовку и хранение координат.
* `Player` — наследник `GameSprite`, реализующий управление с клавиатуры и ограничение выхода за границы экрана (`700x500`).
* `Enemy` — наследник `GameSprite`, реализующий автоматическое движение противника в заданном диапазоне по оси X (`270` – `510`).
* `Wall` — класс для генерации цветных прямоугольных препятствий (стен лабиринта).
